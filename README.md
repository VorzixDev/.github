# VorzixDev Organization Defaults

This repository contains the public VorzixDev organization profile and default community health files used across eligible repositories.

## Files

- `profile/README.md` — Public organization overview
- `CODE_OF_CONDUCT.md` — Community and contributor conduct
- `CONTRIBUTING.md` — Default contribution guidance
- `SECURITY.md` — Responsible vulnerability disclosure
- `SUPPORT.md` — Product and repository support guidance
- `GOVERNANCE.md` — Public project-governance structure
- `ISSUE_TEMPLATE/` — Default bug and feature-request forms
- `PULL_REQUEST_TEMPLATE.md` — Default pull-request checklist

Repository-specific files may override these defaults.
