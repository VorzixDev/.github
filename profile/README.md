# VorzixDev

**Building modular systems, digital products, game-development assets, and practical software for creators and developers.**

VorzixDev is an independent development studio currently focused on Roblox systems and developer products. Our long-term direction may expand into original Roblox experiences, Unity and Unreal Engine assets, desktop software, AI-assisted tools, and other digital products.

## Current Focus

- Modular Roblox systems and reusable development products
- Luau systems engineering and Roblox Studio integration
- Product documentation, testing, and support
- Commercial assets created for developers and creators

## Current Projects

- **Advanced NPC Dialogue System** — Released
- **Ultimate Door & Access System Pack** — In development

Project names, scope, release plans, pricing, and availability may change during development. Official releases are announced through VorzixDev's verified channels.

## Future Direction

VorzixDev may later develop or publish:

- Original Roblox experiences
- Unity and Unreal Engine assets
- 2D and 3D game-development resources
- Desktop software and utilities
- Local or desktop AI-assisted tools
- Additional developer-focused digital products

These areas describe long-term direction, not guaranteed releases.

## Community and Contributions

VorzixDev works with project-based contributors across software development, scripting, UI/UX, 2D and 3D art, animation, VFX, sound design, documentation, and quality assurance.

A GitHub role, repository contribution, pull request, Discord role, or project discussion does not automatically create employment, compensation, revenue-share, ownership, or intellectual-property rights. Project-specific commercial work requires separately accepted written terms.
