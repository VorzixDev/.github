# VorzixDev

**Modular systems and practical digital products for game developers and creators.**

## What We Do

VorzixDev is an independent development studio focused on building modular systems and practical digital tools for game developers and creators.

Our current work focuses on:

- Modular Roblox systems and reusable Luau frameworks
- Developer-focused game systems and tools
- Configurable, integration-friendly digital assets
- Product documentation, testing, and technical support

## Featured Work

### Advanced NPC Dialogue System

A modular Roblox dialogue system designed for reusable NPC interactions, cinematic camera behavior, dialogue responses, and cross-platform controls.

- Status: Released
- Platform: Roblox Studio
- Store: https://vorzixdev.gumroad.com
- Demo: https://www.youtube.com/@vorzixdev.official

### Ultimate Door & Access System Pack

A modular door and access-control product currently in development for Roblox Studio.

- Status: In Development
- Platform: Roblox Studio
- Public details will be shared as development progresses.

## Future Direction

VorzixDev may gradually expand into additional game-development platforms, digital assets, desktop software, and developer-focused AI tools. These areas represent long-term direction rather than guaranteed releases.
